# LNURL Pay ⚡️

> **Retired.** This project is no longer maintained. Invoice generation on [lnurlpay.com](https://lnurlpay.com) has stopped. The site remains online with a retirement notice only.

For LNURL specifications, see the [LNURL LUDs repository](https://github.com/lnurl/luds).

Web app that formerly generated BOLT11 invoices from an LNURL or Lightning Address.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
